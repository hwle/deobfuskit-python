# DeobfusKit Python

A companion learning tool that restores names in source transformed by **ObfusKit Python** when its mapping JSON is available. Without that mapping, it can normalize formatting only if you add a formatter yourself; it cannot reliably recover original names or comments.

## Usage
```bash
python deobfuskit.py build/sample_obfuscated.py --map build/sample.map.json -o build/sample_restored.py
```

## Safety and limitations
- Works with mapping files generated by ObfusKit.
- Token-aware replacement avoids changing identifier-like text inside strings and comments.
- Validates that the result parses as Python.
- Does not claim to reverse arbitrary third-party obfuscation.
- Review outputs before running code from an untrusted source.
